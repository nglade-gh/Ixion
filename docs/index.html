Vue d'ensemble

Shooter est un shooter vertical inspiré de Xenon 2, développé avec le framework MonoGame en C# et ciblant .NET 6.

  • Cible : DesktopGL (Windows/Linux/macOS)
  • Résolution : 600×800
  • Framework : MonoGame.Framework.DesktopGL 3.8.1.303
  • Langage : C# 10 (.NET 6)
  • Données : Tous les paramètres de jeu sont chargés depuis des fichiers XML (Content/config/)
  • Assets : Graphismes vectoriels réduits d'un facteur 4–5, générés procéduralement ou importés de packs libres

Architecture

Le projet suit une hiérarchie de classesSprite rigoureuse :

  • Sprite : base de tout ce qui est dessiné (texture, position, rotation, origine, AABB).
  • Entite : ajoute la physique (vitesse/accélération), les PV, la régénération et le tir.
  • Personnage : personnage contrôlé (score, vies, invincibilité). Player en hérite.
  • Creature : entité animée avec patterns de déplacement et d'attaque. Enemy en hérite.
  • Decors : éléments de décor défilants (parallax, murs, astéroïdes). DecorElement en hérite.

Le GameplayScreen orchestre toutes les entités, gère les collisions, les spawns, les bonus et le HUD. Les paramètres sont centralisés dans le singleton GameConfig, lu depuis des XML via XmlConfig.

Configurations XML

Tous les paramètres se trouvent dans Content/config/ :

  • entities.xml : player (taille, PV, vitesse, rotation), enemy (base).
  • enemies.xml : archetypes d'ennemis (Scout, Fighter, Tank, Elastic, Kamikaze) avec HP, vitesse, patterns, patterns de tir, couleurs.
  • decors.xml : murs latéraux, plafond, astéroïdes, étoiles (parallax).
  • bullets.xml : 5 types de projectiles (joueur primaire, plasma, spécial, ennemi, homing).
  • bonuses.xml : 3 bonus (PrimaryUpgrade, SecondaryUpgrade, SpecialAmmo).

Gameplay & contrôles

Contrôles

ToucheAction
Flèches / WASDDéplacement du vaisseau
EspaceTir primaire (canon rapide, 30/s, dégâts faibles)
XTir secondaire (plasma, 2/s, dégâts moyens)
CTir spécial (rare, nécessite munitions)
EntréeMenu / restart après Game Over

Mécaniques

  • Upgrades : Les bonus upgradent le tir primaire ou secondaire pendant 8s (dégâts ×2, changement de couleur).
  • HUD : Score, vies, vague, barre de PV, munitions spéciales, décomptes d'upgrade.
  • Difficulté progressive : Le spawn rate augmente avec la vague.
  • Missiles homing ennemis : Destructibles par les tirs du joueur, valent 5 points.

Build & exécution

cd ~/Documents/Prog/dotnet/Programs/MonoGames/Shooter
export PATH="$HOME/.dotnet:$PATH"
export DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1
dotnet build

Le binaire produit est bin/Debug/net6.0/Shooter.dll. Exécutez-le avec :

dotnet run

Les assets sont générés par le content pipeline (MGCB) à partir des PNG dans Content/pics/.
