Sprite

Fichier : Sprite.cs

Classe abstraite racine de tout ce qui est dessiné. Gère la texture, la position, la rotation, l'origine et le rendu via MonoGame.

Propriétés

PropriétéTypeDescription
PositionVector2Position centrale du sprite sur l'écran.
SizeVector2Taille logique en pixels (avant Scale).
ScalefloatMultiplicateur uniforme (utilisé pour réduire les assets).
ColorColorTinte de rendu (par défaut blanc).
RotationfloatRotation en degrés (sens horaire).
OriginVector2Point d'origine dans la texture.
BoundsRectangleAABB du sprite (prend en compte la rotation).

Méthodes

  • CreateDotTexture(GraphicsDevice, int, Color) : Texture2D — génère une texture de point radial pour particules/étoiles.
  • CreateTextTexture(GraphicsDevice, string, SpriteFont, Color) : Texture2D — rend du texte en texture.
  • CreateArrowTexture(GraphicsDevice, int, Color) : Texture2D — génère une flèche pour le menu.

Entite

Fichier : Entite.cs

Classe abstraite intermédiaire. Ajoute la physique (vitesse/accélération), les points de vie, la régénération et le mécanisme de tir.

Propriétés

PropriétéTypeDescription
VelocityVector2Vitesse courante en px/s.
AccelerationVector2Accélération courante, remise à zéro chaque frame.
SpeedfloatVitesse maximale.
HPintPoints de vie courants.
MaxHPintPoints de vie maximum.
RegenRatefloatPV regagnés par seconde (0 = pas de regen).
FireCooldownfloatTemps restant avant le prochain tir.
FireRatefloatIntervalle entre deux tirs (secondes).

Méthodes

  • TakeDamage(int) : bool — inflige des dégâts, retourne true si l'entité meurt.
  • TryFire() : bool — retourne true si le tir est autorisé (cooldown écoulé).
  • Update(GameTime) — intègre la physique, le cooldown de tir et la régénération.

Player

Fichier : Player.cs

Vaisseau du joueur. Contrôle les tirs primaire/secondaire/spécial, les upgrades et la collecte de bonus.

Propriétés de tir

Méthodes

  • TryFirePrimary() : bool — tente un tir primaire (30/s).
  • TryFireSecondary() : bool — tente un tir secondaire (2/s, dégâts doublés si upgrade).
  • TryFireSpecial() : bool — tente un tir spécial (consomme une munition).
  • ApplyPrimaryUpgrade(float duration, int ammo) — applique un upgrade temps/munitions au tir primaire.
  • ApplySecondaryUpgrade(float duration, int ammo) — applique un upgrade au tir secondaire.
  • AddSpecialAmmo(int amount) — ajoute des munitions spéciales.
  • SetPlayArea(Rectangle) — définit la zone de jeu autorisée.

Enemy

Fichier : Enemy.cs

Ennemi concret. Définit le comportement de déplacement selon 4 patterns (Sine, Horde, Charge, Zigzag) et 3 patterns de tir (Simple, Burst, Homing).

Propriétés

PropriétéTypeDescription
TargetPositionVector2Cible actuelle du pattern Charge.
ExplosionColorColorCouleur des particules d'explosion.

Patterns de mouvement

  • Sine : oscillation horizontale sinusoidale.
  • Horde : dérive douce en groupe.
  • Charge : descente puis plonge vers le joueur.
  • Zigzag : changements de direction brusques gauche/droite.

GameplayScreen

Fichier : GameplayScreen.cs

Écran principal de jeu. Orchestre toutes les entités, gère les collisions, les spawns, les bonus et le HUD.

Responsabilités

  • Chargement des textures et initialisation des entités.
  • Boucle de jeu : Update (input, spawn, collisions, AI) + Draw (décor, entités, HUD).
  • Gestion des 3 modes de tir (primaire, secondaire, spécial) avec leurs upgrades respectifs.
  • Système de collisions AABB avec marges de tolérance.
  • Drop de bonus (8% de chance) et application des effets.
  • Difficulté progressive (augmentation du spawn rate).

GameConfig

Fichier : GameConfig.cs

Singleton chargeant toutes les configurations XML. Fournit des valeurs par défaut robustes si un fichier est absent ou corrompu.

Méthodes

  • LoadAll() — charge tous les XML (entities, enemies, decors, bullets, bonuses).
  • ContentKey(string) : string — convertit un chemin de texture en clé de contenu (supprime .png).
  • GetBullet(string) : BulletParams — recherche un projectile par nom.
  • GetEnemyType(string) : EnemyType — recherche un type d'ennemi par nom.
  • GetBonus(string) : BonusParams — recherche un bonus par nom.

XmlConfig

Fichier : XmlConfig.cs

Classes de sérialisation XML et helpers utilitaires.

Helpers statiques

  • ParseColor(string, Color) — parse "r,g,b" ou "r,g,b,a".
  • ParseSourceRect(string) : Rectangle? — parse "x,y,w,h".
  • ParseEnum<T>(string, T) : T — parse un enum, insensible à la casse.

Classes de paramètres

  • EntityParams — base (nom, texture, scale, PV, regen, fireRate).
  • PlayerParams — dimensions, vitesse, vies, invincibilité, rotation.
  • EnemyType — taille, HP, score, patterns de mouvement et de tir, couleur.
  • DecorParams — côté, couche, vitesse, textures multiples, scale.
  • BulletParams — dimensions, vitesse, dégâts, homing, rayon de recherche, couleur.
  • BonusParams — dimensions, vitesse, couleur.
